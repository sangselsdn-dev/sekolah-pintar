Ajukan hubungan keluarga

Catatan: fitur ini masih memerlukan ID akun murid. Mintalah ID kepada admin sekolah; jangan memasukkan kata sandi atau data pribadi lainnya.

Pastikan ID benar dan murid terdaftar di sekolah aktif. Permintaan tidak otomatis memberi akses sebelum disetujui admin.
